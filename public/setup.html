FitHub Database Configuration

To activate your fullstack SQL project, follow these quick steps to hook up your database with Supabase.

1

Create a Supabase Project

Go to supabase.com, log in or sign up for a free account, and create a new project named FitHub.

2

Run the SQL Schema Script

Open the SQL Editor in your Supabase dashboard, click "New Query", paste the entire contents of schema.sql, and click Run. This creates all SQL tables and populates them with initial seed data.

3

Paste Credentials in Env File

Go to your Supabase Project Settings → API. Copy your Project URL and anon public key. Open the local .env file in your text editor and paste them into the SUPABASE_URL and SUPABASE_KEY properties.

4

Restart Server

Stop your node command line session and restart the server by running npm start (or node server.js) to connect to your live SQL database.
